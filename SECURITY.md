# Security Policy

## Reporting Vulnerabilities

If you find a security issue, please email security@whiskerworks.example.com.
Do NOT open a public issue. The cats have enough anxiety already.

## Supported Versions
| Version | Supported |
|---------|----------|
| 2.x     | Yes      |
| 1.x     | Yes      |
| < 1.0   | No (it was a hairball) |
