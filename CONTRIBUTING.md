# Contributing to WhiskerWorks

Welcome! We're excited you want to help make the purrfect cat shop.

## How to Contribute

1. Fork the repo
2. Create a branch (`git checkout -b feature/amazing-cat-feature`)
3. Make your changes
4. Write tests (let your cat walk on the keyboard for extra coverage)
5. Submit a PR

## Code Style
- TypeScript strict mode
- Prettier with default config
- All variable names must be cat-pun-compatible (just kidding... unless?)

## Reporting Bugs
Please use our issue templates. Rate the severity on the Cat Anger Scale:
- Mild hiss: Low priority
- Full hairball: Medium
- Knocked the vase off the table: Critical
